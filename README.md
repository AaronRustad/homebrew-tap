# Aaron Rustad’s Homebrew tap

Homebrew casks for macOS apps.

The SaaStatus cask will be added automatically when the first signed release is published. After that:

```bash
brew tap AaronRustad/tap
brew install --cask saastatus
```

SaaStatus supports macOS 13 or later on Apple Silicon and Intel. [Downloads](https://github.com/AaronRustad/saas-status-releases/releases).
